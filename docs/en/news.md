# News and releases

## v0.1.0 — public release candidate

v0.1.0 is the public foundation of `engineer_kit`.

### Highlights

- streaming-first extraction with a 25,000-record default batch;
- managed and embedded modes;
- safe checkpoints;
- DuckDB, Parquet, and Delta adapters;
- local UI;
- secure-by-default behavior;
- bilingual GitHub Pages documentation;
- PyPI distribution prepared through Trusted Publishing.

See [`CHANGELOG.md`](https://github.com/Lima-Ricardo/engineer_kit/blob/main/CHANGELOG.md) for the detailed history.
