# Notícias e releases

## v0.1.0 — release candidate pública

A v0.1.0 está preparada como a fundação pública do `engineer_kit`.

### Destaques

- extração streaming-first com default de 25.000 registros;
- managed e embedded mode;
- checkpoint seguro;
- DuckDB, Parquet e Delta;
- UI local;
- segurança por padrão;
- documentação GitHub Pages;
- distribuição PyPI preparada por Trusted Publishing.

Veja também o [`CHANGELOG.md`](https://github.com/Lima-Ricardo/engineer_kit/blob/main/CHANGELOG.md).
