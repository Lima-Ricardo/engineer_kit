# Código de Conduta

Este projeto espera colaboração profissional, técnica e respeitosa.

São bem-vindos questionamentos, críticas de design e discordâncias técnicas quando focados no código, nos dados e nos trade-offs.

Não são aceitos assédio, discriminação, ataques pessoais, exposição de informações privadas ou publicação de credenciais/dados sensíveis.

Problemas de segurança devem seguir `SECURITY.md`, não issues públicas.
