2. Incremental / StateStore
Local lab: usa DuckDBStateStore. Fora da UI, o mesmo contrato suporta JsonFileStateStore e DeltaStateStore. O Pipeline nunca consulta a Bronze inteira para descobrir o último checkpoint.
A maior data vista só vira watermark depois que a escrita da Bronze termina com sucesso.
Retries da mesma janela usam uma ingestion_key determinística nos adapters oficiais, evitando duplicação quando o destino confirmou mas o checkpoint falhou.

Projeto local: {{ "encontrado" if dbt_available else "não encontrado ainda" }}. Instale engineer_kit[dbt] ou engineer_kit[local].
