RestConnector

Transforma uma API REST em uma fonte previsível. O usuário declara apenas o que varia: URL, método, autenticação, paginação, caminho dos registros e filtros de data.

API → Iterator[dict]

StateStore

Persiste o checkpoint incremental. O connector pergunta pelo último watermark sem saber se ele vive em DuckDB, Delta ou outro backend.

get_watermark / set_watermark

Destination

Recebe registros e materializa a Bronze. O core não conhece SQL de DuckDB nem detalhes de Lakehouse.

load(...) → LoadResult

RunLogBackend

Registra a execução de forma auditável sem amarrar o Pipeline a uma tabela específica. No local, o adapter é DuckDBRunLogStore.

record(RunLogEntry)

Pipeline

Coordena a unidade atômica: extrai, grava, confirma o watermark e registra auditoria. Pode ser chamado pela UI, Scheduler, Airflow ou outro orquestrador.

state → extract → load → commit

Transform

É deliberadamente pós-ingestão. dbt é uma integração opcional no laboratório local; em uma plataforma robusta, Spark/dbt/SQL podem rodar externamente.

Bronze → staging → silver → gold

Runtime local

A interface é opcional. Instale apenas o que precisar:

# somente interface local
pip install "engineer_kit[ui]"

# somente integração dbt local
pip install "engineer_kit[dbt]"

# laboratório local completo: UI + dbt
pip install "engineer_kit[local]"

engineer_kit ui --workspace .

Nesse modo, o mapa de adapters é:
